# Checks if all geometries are already valid and make valid if not

Checks if all geometries are already valid and make valid if not

## Usage

``` r
st_make_valid_ext(x, ...)
```

## Arguments

- x:

  object of class `sfg`, `sfc` or `sf`

- ...:

  passed on to
  [s2_options](https://r-spatial.github.io/s2/reference/s2_options.html)
